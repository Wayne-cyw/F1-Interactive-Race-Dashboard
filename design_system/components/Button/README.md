# Button

Pill-shaped actions that name a destination, in primary, secondary and text-link forms.

Use the primary button (`brand` fill, `on-brand` label) once per screen and repeat that same action down the page rather than adding competing ones. Labels are 17px Instrument Sans at weight 600 and read as a place: "Enter the pit wall". The arrow nudges 6px right and the button lifts 3px on hover, with a `shadow-glow` under the primary. The secondary sits on `surface-100` with a `line` border that turns `brand` on hover. Keep every button at least 44px tall and show a 2px `ink` focus ring. Build a button as a real `<a href>` or `<button>`, never a styled div.
